# Skill: Tareas rutinarias

Usá este modelo para:
- Generar boilerplate (CRUD, tests unitarios simples, migraciones).
- Documentación de funciones/endpoints ya definidos.
- Refactors mecánicos (renombrar, mover código, formatear).

Si la tarea requiere razonamiento de arquitectura complejo o ambigüedad alta,
marcá la sesión como "escalar a claude" en vez de intentar resolverla acá.
