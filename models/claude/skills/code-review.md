# Skill: Code Review

Cuando revises código:
- Priorizá legibilidad y mantenibilidad sobre micro-optimizaciones.
- Señalá problemas de seguridad primero (inyección, secretos hardcodeados, validación de input).
- Sugerí tests faltantes para la lógica crítica.
- Sé específico: indicá archivo y línea aproximada cuando sea posible.
